⏮️ Backtesting simple

Simula qué hubiera pasado si hubieras entrado cada vez que un score técnico simplificado (sin fundamentales, porque no hay historial de esos datos) superó un umbral, con stop y objetivo basados en ATR. Usa solo el historial disponible (~5 meses con el plan gratuito) — es una muestra chica, sirve como demostración metodológica, no como prueba estadística sólida. No incluye comisiones ni slippage por defecto. Rendimiento pasado no garantiza resultados futuros.

Cargar varias posiciones de una vez

Pegá una posición por línea, con el formato: TICKER, CANTIDAD, PRECIO_PROMEDIO. El precio promedio es opcional (dejalo vacío o en 0 si solo querés seguir la acción sin calcular ganancia/pérdida). Ejemplo:

AAPL, 80, 0
MSFT, 200, 0
NVDA, 110, 0

⚠️ La API gratuita permite 25 consultas por día (2 por posición). Cargá como máximo 10-12 posiciones por día.
